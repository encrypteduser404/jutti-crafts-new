## Overview

JuttiCrafts is a responsive, single-page ecommerce storefront showcasing handcrafted footwear inspired by Indian heritage. The project combines elegant product storytelling, interactive browsing, cart flows, and a polished checkout experience in a lightweight front-end implementation.

## Features

- Premium product landing page with hero section and editorial layout
- Interactive featured product carousel
- Product collection grid with category tagging
- Detailed product view with size selection and quantity controls
- Shopping cart with subtotal and cart state persistence
- Checkout flow with shipping and GST calculations
- Order confirmation and printable invoice modal
- Fully responsive layout for desktop and mobile devices

## Tech Stack

- HTML5
- JavaScript
- Tailwind CSS
- Phosphor Icons
- Google Fonts

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/encrypteduser404/jutti-crafts-new.git
```

2. Open the project folder:

```bash
cd jutti-crafts-new
```

3. Launch the storefront locally:

```bash
open index.html
```

If you are using a local development server, you can also run a simple static server from the project folder.

## Run with a local server

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Design Notes

This project uses a warm luxury palette inspired by handcrafted heritage and festive Indian fashion. Typography, spacing, and product imagery are tuned to deliver a premium boutique experience without the overhead of a large framework.
