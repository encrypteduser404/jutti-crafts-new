A premium single-page storefront for authentic handcrafted juttis, blending traditional Indian artistry with a modern shopping experience.

## Highlights

- Curated collection of handcrafted Punjabi juttis with rich heritage-inspired patterns
- Interactive product browsing with featured carousel and detail pages
- Shopping cart, quantity controls, checkout flow, and printable invoice experience
- Mobile-friendly storefront built with HTML, Tailwind CSS, and JavaScript
- Designed for festive, bridal, and everyday ethnic styling

## Features

- Product gallery with category-based selection
- Detailed product pages with size selection and quantity controls
- Cart and checkout experience with shipping and GST calculations
- Order confirmation and invoice modal for a complete storefront flow
- Responsive layout tuned for desktop and mobile browsing

## Quick Start

1. Clone the repository.
2. Open `index.html` in your browser.
3. Browse the collection, choose a size, and enjoy the storefront interactions.

```bash
git clone https://github.com/encrypteduser404/jutti-crafts-new.git
cd jutti-crafts-new
# open index.html in a browser
```

## Why this project stands out

This storefront showcases how a traditional product category can be presented with a premium, boutique feel while staying lightweight and easy to run. The design uses rich warm tones, handcrafted storytelling, and an interactive shopping journey to make the collection feel immersive without needing a heavy framework.
